# BLACKPINK Landing Page

Landing page musical creada como proyecto de Platzi con ayuda de IA, inspirada en BLACKPINK. El objetivo fue construir una experiencia visual llamativa, interactiva y moderna para promocionar un festival o concierto ficticio con estilo K-pop.

## Descripción del proyecto

Este proyecto es una landing page desarrollada con Next.js, React y TypeScript. Está pensada para presentar una experiencia completa de evento musical, con secciones visuales, interacción con el usuario y elementos dinámicos como carrito, autenticación simulada, tickets, merch, galerías y animaciones.

La idea principal fue practicar el uso de herramientas de IA para acelerar el diseño y la implementación de una interfaz atractiva, manteniendo una estructura clara y fácil de extender.

## Tecnologías utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- Radix UI
- Lucide React
- Vercel Analytics

## Funcionalidades principales

- Pantalla de bienvenida inicial

- Sección de lineup o setlist
- Galería de imágenes
- Testimonios
- Quiz interactivo
- Sección de Spotify
- Videos promocionales
- Ubicación del evento
- Tienda de merchandising
- Compra de tickets
- Preguntas frecuentes
- Carrito de compras
- Modal de autenticación
- Checkout simulado
- Tickets del usuario
- Efectos visuales y animaciones

## Cómo ejecutar el proyecto

### Requisitos previos

- Node.js 18 o superior
- pnpm instalado

### Instalación

```bash
pnpm install
```

### Modo desarrollo

```bash
pnpm dev
```

Luego abre la aplicación en tu navegador en la dirección que aparezca en la terminal, normalmente:

```bash
http://localhost:3000
```

### Build de producción

```bash
pnpm build
```

### Ejecutar en modo producción

```bash
pnpm start
```

## Estructura general

- `app/` contiene el layout y la página principal
- `components/` contiene las secciones reutilizables de la landing
- `public/` almacena recursos estáticos como imágenes e iconos
- `README.md` documenta el proyecto

## Mejoras recomendadas

- Agregar soporte multidioma
- Conectar el carrito con una API real
- Persistir la sesión de usuario con autenticación verdadera
- Crear una pasarela de pago simulada o real
- Mejorar la accesibilidad de los componentes
- Optimizar imágenes y tiempos de carga
- Agregar pruebas unitarias e integración
- Publicar la landing en Vercel con dominio personalizado
